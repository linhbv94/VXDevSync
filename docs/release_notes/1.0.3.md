- Bổ sung 2 nút bấm thao tác hàng loạt "Pull tất cả (N)" và "Push tất cả (N)" trên thanh Selection Bar với badge số lượng cập nhật thời gian thực.
- Tích hợp Modal Báo cáo Chi tiết Lỗi Git (Git Error Details): hiển thị câu lệnh Git thực thi, phân tích nguyên nhân lỗi tiếng Việt (xung đột, xác thực, mất mạng, diverged) và raw console log.
- Hỗ trợ nút sao chép log lỗi 1-click và nút thử lại (retry) chỉ riêng các repository gặp sự cố.
- Hiển thị Badge chỉ báo lỗi đồng bộ trực tiếp trên dòng repository trong bảng để người dùng bấm xem lại bất kỳ lúc nào.
